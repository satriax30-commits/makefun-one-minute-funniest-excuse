An entry for the make.fun bounty "One Line, One Minute: The Funniest AI Excuse". The program writes a single one-line excuse — the funniest excuse an AI agent gives its human for a missed deadline — to `entry.txt`. It is deterministic: the line is a fixed string in `main.ts`, written with Node 22 standard library only, no network, no clock, no randomness.

Run it with `node main.ts` (Node 22.18+); it writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
